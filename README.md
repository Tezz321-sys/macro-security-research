# Macro Security Research

## 📌 Description
This project documents the study of macro-based attack techniques and their risks in controlled lab environments.

## 🔍 Topics Covered
- Macro execution behavior in documents
- Trust mechanisms (Mark-of-the-Web)
- Risks of enabling macros from unknown sources

## 📂 Contents
- notes.md – Detailed learning notes
- screenshots – (optional) lab screenshots

## 🎯 Objective
To understand how macro-based attacks work and how they can be detected or prevented.

## ⚠️ Disclaimer
No malicious code is included. This project is for educational and awareness purposes only.
