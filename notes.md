# Macro Security Notes

## What are Macros?
Macros are scripts embedded in documents to automate tasks.

## Security Risks
- Can execute code when document is opened
- Often used in phishing attacks

## Key Learning
- Never enable macros from unknown sources
- Trust indicators like Mark-of-the-Web affect execution

## Defensive Measures
- Disable macros by default
- Use antivirus and endpoint protection
